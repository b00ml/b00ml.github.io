# 判断归模型，机械归脚本

博客发布工具拆成两半：CLI 负责全部确定性动作（方言转换、图片搬运与哈希校验、构建、提交、推送、部署等待与验证），agent skill 负责全部判断（标题、描述、标签、slug、内容检查、英文提交信息）。CLI 不做任何猜测——缺字段就停下要人给，不猜一个。

选它而不选纯 CLI，是因为这些字段本质是判断题，写成脚本只能是启发式，而「猜得还行」比「明确要你给」更危险：用户会懒得看，错的内容静默上线。选它而不选纯 skill，是因为图片搬运、哈希校验、构建、推送这些让模型每次现场发挥既慢又不可靠，而它们恰好可以做到完全确定。

**Consequences**: CLI 无法独立完成一次发布，必须由人或模型补判断；工具被拆成两个可独立演进的半边。
