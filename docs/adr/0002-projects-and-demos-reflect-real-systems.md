# 项目只收录有真实代码库的系统，交互演示只还原真实后端机制

`/projects` 集合只收录由作者实际构建、具备可运行工程代码库与自动化验证体系的软件系统；纯方案推演、静态课题原型与商业算账拆解一律写成 `/product` 下的文章，不挂空壳原型。同时，项目下的在线交互演示只用于在浏览器里零安装还原真实后端已实现的状态流转与护栏边界，不做脱离代码实现的营销概念落地页。

选它而不把所有原型都塞进项目列表，是因为招聘方与技术面试官会以最弱的一张卡片推断整站水分：一旦把无后端正则原型与千级测试的真实系统并列，其他项目的交互演示也会被连带怀疑成假壳子。

**Consequences**: 项目数量保持少而硬（当前固定为三个核心系统，全员配备交互演示与架构图）；偏业务诊断与立项测算的课题成果通过产品思考文章沉淀，不稀释项目区的工程可信度。
