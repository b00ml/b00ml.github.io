# 数据统计

本站**没有**接入任何统计：没有埋点脚本、没有事件契约、没有浏览量计数。这是 v1 的取舍，不是漏做。

## 之前有什么

上游模板带一套完整的 Vercel Web Analytics + Umami 事件契约，38 个事件。它随模板的其他机制一起被删掉，
而它盯的那些界面（终端 dev mode、开场动效、agent-teams、talks、赞助、联系页、英文站）现在也都不存在，
那些事件永远不会触发。要取回那份契约：

```
git show 0a6ae44:ANALYTICS.md
```
