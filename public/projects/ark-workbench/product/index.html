02 · 收集与任务，一份 Markdown 多维透视

不建私有库。关掉插件，你的待办和摘录依然是普通笔记。

采集进来的文章视频和每日推进的任务，全部以标准 Markdown + Frontmatter 落在你的 Vault 目录里。 在界面上它是顺手的收件箱、多标签看板、月度热力与共现精力流向图；在磁盘上它永远受 Git 快照和全文检索保护。

03 · 记忆防污染与安全边界

分得清「模型猜的」与「你亲口认的」，也守得住不可逆边界。

长期记忆最怕模型把一句随口推测当成你的永久偏好。Ark 在数据结构上把推断与结论彻底分开，并把整套系统收敛进五条不能破的硬约束。

remember 工具没有直接写 confirmed 的参数：一切抽取结果默认带 [推测，未确认] 且绝不进入 2k 常驻层；确认后记录来源通道 via，误确认可按通道一键批量降级。

五条不可妥协的硬约束

凡是 Git 快照能兜住的地方都不弹窗打断你；只在这五条底线上强制守死：

  • 1. 原始素材只读：raw/ 与隐藏配置（.git/、.env、ark.toml）由路径守卫硬拒写。
  • 2. 一次操作一个快照：按用户意图而非单次工具调用合并提交 ark(<source>)，git revert 撤销不改写历史。
  • 3. 外部写动作必审：发邮件、对外发布不可逆，回环内暂停推 pending_action，拒绝结果如实回填给模型。
  • 4. 自有调用双上限预算：单次会话与每日 Token 双封顶，超出先截记忆再截断点并显式报告。
  • 5. 凭据只进 .env：绝不进仓库、不进 Vault 笔记、不落明文轨迹。
